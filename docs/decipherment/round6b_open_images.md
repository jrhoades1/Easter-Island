## What counted as open

Open, for the recheck in this note, means CC0 or CC BY stated on the holding institution's own page. CC BY-SA, CC BY-NC, CC BY-NC-SA, all rights reserved, and a usage line that says "Not determined" stay outside that gate. A license printed only on Wikimedia Commons was not copied in as the holder's license. CEIPP drawings were already checked in Round 5B and are not photographs.

A disagreement, had one been logged, would use the same fields as `data/decipherment/round5b_ceipp_recheck.json`: `passage`, `position`, `repo_code`, `drawing`, `confidence`, `horley_pozdniakov_guy`, and `adopted`. The list in this round is empty. `adopted_corrections` is empty.

No image file was committed. Berlin's JPEGs were fetched to a temporary directory only to read pixel size. They are CC BY-NC-SA and were left there.
